About Project

Automobile Sales Data Warehouse and Mining System

Project Objective

MotorIQ is a Data Warehouse and Data Mining system designed to analyze automobile sales data using dimensional modeling, OLAP operations and analytical queries.

Data Warehouse

The system uses a Star Schema consisting of the Fact Sales table and dimensions such as Date, Customer, Vehicle, Dealer and Location.

OLAP Operations

The system supports Roll-Up, Drill-Down, Slice and Dice operations for multidimensional analysis.

Data Mining

Mining modules identify sales trends, top companies, popular models, dealer performance, customer patterns, vehicle preferences and regional trends.
